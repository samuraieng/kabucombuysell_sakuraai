# kabucombuysell_sakuraai

三菱UFJ eスマート証券（旧カブドットコム証券）の **kabuステーションAPI** (kabusapi) を利用した自動取引支援ツール。

4種類の設定ファイル（買い / 売り / 信用返済 / 売らない）の条件に従い、周期処理で現物買い・現物売り・信用返済を自動発注します。また、保有銘柄一覧をワンショットで確認できるスクリプトも同梱しています。

- APIリファレンス: https://kabucom.github.io/kabusapi/reference/index.html

## 機能概要

- **自動取引エンジン (`kabu_trade.py`)**
  - 設定ファイルに基づき、現物買・現物売・信用返済を周期的に自動発注
  - 市場時間限定稼働、周期インターバル指定、安全なシミュレーションモードに対応
- **保有銘柄一覧表示 (`get_stocks.py`)**
  - 現在保有中の現物株および信用建玉の一覧（数量・取得単価・時価・評価損益）をワンショットで取得・整形表示

## 対応する取引と判定条件

| 取引種別 | 対象 | 発注条件 |
|---|---|---|
| スイング・長期保有 | 現物買 (特定口座) | **条件#1**: 指定価格で指値買 (0指定時は成行)<br>**条件#2**: 現在値がトリガー価格以下で成行買 (0指定時は無効)<br>※両方指定時は条件#2を優先 (成行)<br>※約定反映確認後、買設定ファイルの該当行に自動で `#` を付与して無効化 |
| スイング・長期保有 | 現物売 (特定口座) | **条件#3**: 指定価格で指値売 (0指定時は成行)<br>**条件#4**: 現在値がトリガー価格以上で成行売 (利確、0指定時は無効)<br>※数量0または保有数超過指定時は全数売り<br>※売らないリストに記載の銘柄は除外<br>※未約定の売注文がある銘柄は重複発注を防止 (条件#4成立時は指値取消→成行切替) |
| デイトレ等 | 信用返済 (買建・売建) | **条件#5**: 目標差益で指値返済 (買建: 買値 + spread / 売建: 売値 - spread)<br>**条件#6**: 損失拡大で成行損切り (買建: 買値 - 5×spread / 売建: 売値 + 5×spread)<br>※spread (指定金額) は空欄/0で呼値単位 (最小変動単位) を自動適用<br>※損切り条件成立時は既存返済注文を取り消して成行で再発注 |
| 除外 | 売らないリスト | 記載銘柄は現物売り対象から除外 |

※ 信用の新規建ては自動化対象外 (手動オペレーション)。

## セットアップ

### 1. 依存パッケージ
```bash
pip install -r requirements.txt
```
依存ライブラリは `requests` のみです。

### 2. 環境変数の設定
```bash
export KABU_API_HOST="localhost"          # kabuステーション動作ホスト (既定: localhost)
export KABU_API_PORT="18080"              # 本番ポート (既定: 18080 / 検証は +1)
export KABU_API_PW_PROD="<本番パスワード>"   # kabuステーションのログインパスワード (必須)
export KABU_API_PW_DEV="<検証パスワード>"    # 検証環境を使う場合のみ
```

## 使い方

### 1. 保有銘柄の確認 (`get_stocks.py`)
```bash
python get_stocks.py
```

### 2. 自動取引の実行 (`kabu_trade.py`)
```bash
# 1回だけ実行 (既定)
python kabu_trade.py --mode dev          # 発注表示のみ (実取引しない)

# 60秒ごとに繰り返し実行 (本番取引)
python kabu_trade.py --mode prod --cycle 60

# 待機なしで連続実行 (dev モード)
python kabu_trade.py --mode dev --cycle 0

# 10分ごとに市場時間 (9:05-11:30, 12:30-15:24) のみ稼働
python kabu_trade.py --mode prod --cycle 600 --market-hours
```

### コマンド引数
| 引数 | 説明 | 既定値 |
|---|---|---|
| `--mode` | `prod`=実取引 / `dev`=発注表示のみ (実取引しない) | `prod` |
| `--cycle` | `0`=待機なし連続 / `1..3600`=秒間隔 / `9999`=1回のみ | `9999` |
| `--market-hours` | 市場時間 (9:05-11:30, 12:30-15:24) のみ稼働 | 未指定 (Ctrl+Cまで) |
| `--buylist` | 買設定ファイルのパス | `./list_buy.txt` |
| `--selllist` | 売設定ファイルのパス | `./list_sell.txt` |
| `--retlist` | 信用返済設定ファイルのパス | `./list_ret.txt` |
| `--sellnolist` | 売らないリストのパス | `./list_no_sell.txt` |

## 設定ファイル書式と安全機能・テスト
- カンマ区切りCSV形式（ヘッダー自動スキップ、`#` / `//` コメント対応）。
- **安全機能**:
  - ワンショット上限エラー (`Code=4003001`) や決済指定内容エラー (`Code=8`) 発生時は60秒のクールダウンで連続誤発注を抑制。
  - 信用返済時は建玉個別指定 (`ClosePositions`) と返済可能数量 (`LeavesQty - HoldQty`) を使用し、建玉市場コードを引き継ぎ。
  - API流量制限 (秒間10件) に対するスロットリング (0.12秒間隔) と429リトライ機能。
- **テスト**: `python -m unittest discover -s tests` （全84件の単体テスト）
